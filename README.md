# Comms (GitHub Pages & Local Network)

Minimal flat Nordic communications dashboard and live chat room.

## Features

1. **📱 Comms Dashboard**:
   - **Custom Message & Alert**: Input field to type custom message, with a prominent button: `Send Alert Notification`.
   - **Online Chat CTA**: Positioned above Contacts with a prominent, large flat button: `Open Chat Room`.
   - **Contacts**: Compact list of contacts (Indrajith, Lechu, Alee, Adithyan, Lezin, Deepu, Bipha, Gopika, Nandil) with 1-tap call and copy.

2. **💬 Online Chat**:
   - Flat Nordic color scheme (Polar Night `#2e3440`, Frost `#88c0d0`, Aurora `#a3be8c` / `#b48ead`).
   - Zero emojis across the entire interface.
   - **Invite Contact Option**: Clean `Invite` button in the chat header that opens a contact list modal to send an invitation requesting any member to join the chat room (ready for future email dispatch integration).
   - Display name modal with random generator and real-time Firestore sync.

---

## Access & Deployment

- **Local Wi-Fi Network**: `http://192.168.0.182:8000/index.html`
- **GitHub Pages**: Ready for deployment via **Settings > Pages > Deploy from branch (`/website`)**.
